# Modelo

A full-stack e-commerce web application built using the MERN stack.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Google OAuth 2.0
- Razorpay
- Nodemailer
- Tailwind CSS

## Features

- User registration and authentication
- JWT-based authentication
- Google OAuth login
- Seller registration and management
- Product management
- Order management
- Admin seller approval
- Razorpay payment integration
- Email notifications
- Location-based seller information

## Project Structure

frontend/ - React frontend
backend/ - Node.js/Express backend
